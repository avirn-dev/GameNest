## 4. DATA COLLECTION AND LOCAL PROCESSING

### 4.1 Game Installation Detection

GameNest is designed to scan and detect installed games on your local machine exclusively to provide functionality and features related to game modification and analysis. The Software performs the following data collection activities:

#### 4.1.1 Local Directory Scanning

The Software scans your local file system, including but not limited to:

- Standard game installation directories (Program Files, Steam install folders, Epic Games install folder, etc.);
- User-specified custom directories;
- Registry entries (on Windows systems) related to game installations;
- Game executable files and metadata to identify game titles, versions, and installation locations.

#### 4.1.2 Scope of Scanning

The Software's scanning is limited to directories and locations that are:

- Standard game installation directories known to the Software;
- Custom directories explicitly selected by you;
- Public system areas where game installations are typically stored.

**The Software does NOT:**

- Scan or access your personal documents, photos, videos, or private files;
- Scan encrypted directories without your authorization;
- Scan files in password-protected directories without explicit permission;
- Access system-protected directories or areas requiring elevated privileges (except as necessary for game detection);
- Scan network drives or cloud storage services without explicit user selection.

### 4.2 Data Processing Location

**ALL DATA PROCESSING CONDUCTED BY GAMEEST OCCURS EXCLUSIVELY ON YOUR LOCAL CLIENT MACHINE.** The Software performs all scanning, analysis, and processing of detected game installations entirely within your device's memory and storage. No scanning results, detected games, file paths, or game metadata are transmitted to external servers, cloud services, or third-party entities without your explicit knowledge and consent.

### 4.3 Local Storage

Detected game information may be stored locally on your device in the following manner:

- Configuration files containing paths to detected games;
- Cache files containing game metadata (game titles, versions, installation locations);
- Local database entries for application functionality.

These files remain on your local machine and are not transmitted externally unless you explicitly enable telemetry or cloud synchronization features (see Section 5).

## 5. TELEMETRY AND DATA TRANSMISSION

### 5.1 Telemetry Opt-In

GameNest may offer optional telemetry features that transmit certain data to external servers for purposes including but not limited to:

- Analytics regarding Software usage patterns;
- Bug reporting and crash diagnostics;
- Feature usage statistics;
- Error logging.

**Telemetry is OPT-IN ONLY.** By default, the Software does NOT collect or transmit telemetry data. Telemetry is only active if you explicitly enable it during installation or in the Software's settings.

### 5.2 Telemetry Data Categories

If you opt in to telemetry, the following non-personally-identifiable data may be collected and transmitted:

- Software version number;
- Operating system version and architecture;
- System hardware specifications (CPU, GPU, RAM);
- Application usage frequency and duration;
- Feature usage patterns (anonymized);
- Error codes and crash dumps (may be automatically reported);
- Approximate geographic location (country/region level only, derived from IP address).

**Telemetry data does NOT include:**

- Your personal name or contact information;
- Gaming account information or usernames;
- Game file contents or personal game progress;
- Files, documents, or personal data from your device;
- Precise geographic location or GPS coordinates;
- Browsing history or activity on other websites;
- Financial or payment information.

### 5.3 Telemetry Retention

Telemetry data transmitted to external servers shall be retained in de-identified, aggregated form for a period not to exceed 12 months unless required by law to retain such data for longer periods. After such retention period, data shall be securely deleted or further anonymized.

### 5.4 Disabling Telemetry

You may disable telemetry collection and transmission at any time through the Software's settings or preferences menu. Upon disabling telemetry, no further data transmission shall occur, with the exception of any data already transmitted prior to disabling the feature.

### 5.5 Third-Party Telemetry Services

If telemetry is enabled, the Software may utilize third-party analytics services (such as Google Analytics, Mixpanel, or similar platforms) to process and store aggregated usage data. These third-party services maintain their own privacy policies, and we encourage you to review those policies for additional information regarding their data practices.
